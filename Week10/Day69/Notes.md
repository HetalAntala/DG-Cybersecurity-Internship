🔹 Objective
To create and apply a Group Policy Object (GPO) to restrict user access.

🔹 Tools Used
Windows Server 2016
Group Policy Management Console

🔹 Configuration Performed
Created a new GPO named User_Restrictions_GPO
Disabled Control Panel access
Blocked Command Prompt
Disabled Task Manager
Linked GPO to domain users

🔹 Result
User restrictions were successfully enforced after policy update.

🔹 Learning Outcome
Learned centralized user management and security enforcement using GPO.
